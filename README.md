# 부동산마스터 · 입찰가 계산기

경·공매 입찰가 산정용 단일 페이지 계산기. 체크리스트 형태로 입력하면 자동으로:

- **취득세** 자동 계산 — 1.1% / 3.3% / 3.5% / 8.4%(부가세 포함) / 12.4%(부가세 포함) 중 선택
- **전용면적 85㎡ 초과** 시 농어촌특별세 0.2~0.6% 추가 가산 안내 표기
- **매매사업자 양도소득세** 실효세율(기본세율 × 1.1, 지방소득세 포함) + 누진공제 반영
- **최종 순이익** 자동 산출

## 입력 항목
입찰가 · 매도가 · 전용면적 · 취득세율 · 부대비용 · 명도비 · 미납관리비 · 수리비 · 대출이자 · 중개수수료

## 결과
- 양도차액 = 매도가 − 입찰가
- 과세표준 = 양도차액 − (취득세 + 그 외 비용 합계)
- 양도세(지방세 포함) = (과세표준 × 기본세율 − 누진공제) × 1.1
- 순이익 = 과세표준 − 양도세

## 세율표 (매매사업자 양도소득세, 지방세 1.1배 포함 실효)

| 과세표준 | 기본세율 | 누진공제 | 실효 |
|---|---|---|---|
| 1,400만 이하 | 6% | - | 6.6% |
| 1,400만 초과 ~ 5,000만 이하 | 15% | 126만원 | 16.5% |
| 5,000만 초과 ~ 8,800만 이하 | 24% | 576만원 | 26.4% |
| 8,800만 초과 ~ 1.5억 이하 | 35% | 1,544만원 | 38.5% |
| 1.5억 초과 ~ 3억 이하 | 38% | 1,994만원 | 41.8% |
| 3억 초과 ~ 5억 이하 | 40% | 2,594만원 | 44.0% |
| 5억 초과 ~ 10억 이하 | 42% | 3,594만원 | 46.2% |
| 10억 초과 | 45% | 6,594만원 | 49.5% |
